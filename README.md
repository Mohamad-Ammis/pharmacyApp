# Dawa Tech  
**Dawa Tech** A pharmacy management app with a mobile app and admin dashboard. Users browse products, create orders, and track statuses. Admins can add and modify products, view orders, and manage all aspects of the pharmacy.
## Features

1. **User Account Creation & Login**: Easily create an account or log in to access personalized features.
2. **Browse All Products**: Explore all available products or filter by popular items or recently added ones.
3. **Category-Based Browsing**: Browse products organized into specific categories for more streamlined shopping.
4. **Product Details Page**: View detailed information for each product, including images, descriptions, ratings, and more.
5. **Favorites List**: Add products to your favorites for easy access and future reference.
6. **Shopping Cart & Orders**: Add products to your cart, create orders, and track their status effortlessly.
7. **Search within Categories**: Find products quickly by searching within specific categories.
8. **Multilingual Support**: Use the app in multiple languages to suit your preferences.
9. **Dark/Light Mode**: Toggle between dark and light modes for a comfortable user experience.
10. **Track Order Status**: Follow the status of your order, from processing to delivery.

To run the app, use these commands:
```
flutter pub get
flutter run
```
